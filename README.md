# Бот для проверки статуса домашних работ (Практикум Домашка)

Бот периодически опрашивает API сервиса "Практикум Домашка" и при изменении
статуса отправленной на ревью домашней работы присылает уведомление в VK.
Все важные события логируются, а ошибки уровня `ERROR` дублируются сообщением
в VK.

## Возможности

- Опрос API Практикум Домашка каждые 10 минут.
- Отправка уведомлений в VK при изменении статуса домашней работы.
- Логирование работы в стандартный поток `sys.stdout`.
- Отправка сообщений об ошибках уровня `ERROR` в VK.
- Защита от спама: одна и та же ошибка отправляется в VK только один раз.
- Проверка обязательных переменных окружения при старте.

## Требования

- Python 3.9+
- Доступ к API Практикум Домашка (токен `PRACTICUM_TOKEN`).
- Токен VK-бота и ID пользователя, которому отправляются сообщения.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
```

### 2. Создание и активация виртуального окружения

**Windows (cmd):**

```bash
python -m venv venv
venv\Scripts\activate
```

**Windows (PowerShell):**

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

После активации в начале строки терминала появится префикс `(venv)`.

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте в корне проекта файл `.env` со следующим содержимым:

```bash
PRACTICUM_TOKEN = ваш_токен_практикума
VK_TOKEN = ваш_токен_vk_бота
VK_USER_ID = ваш_id_в_vk
```

⚠️ Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.

Где взять значения:

- `PRACTICUM_TOKEN` — токен из личного кабинета Практикум Домашка.
- `VK_TOKEN` — токен сообщества/бота VK с правами на отправку сообщений.
- `VK_USER_ID` — числовой ID пользователя VK, которому будут приходить
  уведомления.

### 5. Запуск бота

```bash
python homework.py
```

После запуска бот начнёт каждые 10 минут опрашивать API и логировать свою
работу в консоль.

Остановить бота можно сочетанием клавиш `Ctrl+C`.

## Логирование

Логи выводятся в `sys.stdout` с использованием `StreamHandler`.
Формат строки:

YYYY-MM-DD HH:MM:SS,mmm [LEVEL] Сообщение

Уровни важности:

| Уровень  | Когда используется                    |
|----------|---------------------------------------|
| DEBUG    | Успешная отправка сообщения в VK,     |
|          | отсутствие новых статусов.            |
| INFO     | Информационные события.               |
| WARNING  | Предупреждения.                       |
| ERROR    | Сбои при запросе к API, отправке      |
|          | сообщения, отсутствие ключей в ответе.|
| CRITICAL | Отсутствие обязательных переменных    |
|          | окружения при старте.                 |

---

## Переменные окружения

| Переменная        | Обязательна | Описание                     |
|-------------------|-------------|------------------------------|
| `PRACTICUM_TOKEN` | Да          | Токен для доступа к API      |
|                   |             | Практикум Домашка.           |
| `VK_TOKEN`        | Да          | Токен VK-бота для отправки   |
|                   |             | отправки сообщений.          |
| `VK_USER_ID`      | Да          | ID пользователя VK, которому |
|                   |             | шлются уведомления.          |

Если хотя бы одна из переменных отсутствует, бот останавливается с уровнем
логирования `CRITICAL`.
